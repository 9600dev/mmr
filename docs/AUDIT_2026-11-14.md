### B7. Found while fixing (second pass, still open)

* **Gauntlet S3 now fails strategies that cannot signal on a single-instrument frame** (`PairsZScore`, `Global`, the panel / lowfreq classes). That is the conservative answer — the battery could not exercise them — but for a legitimately multi-instrument strategy it should be "not evaluable by this battery", which the pinned verdict (`tests/invariants/test_gauntlet_verdict.py`) has no status for on S3. A spec decision.
* The gauntlet reads the session from CLASS attributes, not from a deployment's `params:`; PASS records stored under the old vacuous stages are not invalidated.
* Panel short-borrow accrual still divides by the nominal bars per year (same root cause as B4.4), so it overcharges on extended-hours intraday panels.
* `VbtMacdBB.BB_ALPHA = 2` now refuses fractional grids until its default is declared `2.0`.
* The backfill hold ends when its three retries are exhausted, and a strategy deployed AFTER startup gets neither a backfill nor a hold.
* The unpickler is now the pure-Python implementation (it has to intercept REDUCE / BUILD): Ticker decode 0.02 → 0.14 ms, Trade 0.04 → 0.23 ms. Residual: an allowlisted object can still carry arbitrary attribute values; oversized payloads are not bounded.
* `docker.sh`: `compose down -t 30` and the health template were verified against a fake runtime only, not podman.
* `pair_fills_long_only` deliberately caps an oversized SELL at the lot without counting it unmatched (`test_sell_capped_at_lot_counts_once`); the review's suggestion to count the excess was tried and reverted.
